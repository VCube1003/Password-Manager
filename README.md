# Password-Manager
CS193 final project - building a CLI-based password manager in Java

Project Goal: Make a password manager in Java to safely store all of the user's passwords in one place
MVP scope: CLI-based password manager with encryption features, data storage in a plain text file and ability for the user to do CRUD operations

Tech Stack:
Language: Java
Libraries: javax.crypto (encryption features), BufferedReader & PrintWriter (File I/O)
Data storage: Plain text file
IDE: IntelliJ

Future Plans (additional features):
1. Password strength checker
2. Random password generator
3. Warning the user if the given password is one of the 10,000 most common passwords
